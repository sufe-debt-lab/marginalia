# 用户文档

这些文档面向使用 Marginalia 的用户，重点是如何配置、使用和理解当前产品边界。

Marginalia 当前处于 Alpha / NO-GO。能力状态和发布阻断见[产品状态](../product/status.md)。用户文档只描述当前可用行为，不从历史 spec 推导功能。

## 文档

- [使用指南](./guide.md) — workspace、provider、对话、文件上下文、权限和故障排查。
- [配置](./configuration.md) — provider 预设、API key、存储位置、环境变量、文档读取限制。
- [核心术语](./concepts.md) — workspace、session、quick chat 等概念与产品边界。
- [产品状态](../product/status.md) — 当前能力、限制和验证快照。

## 推荐阅读顺序

第一次使用：根 README → [使用指南](./guide.md) → [配置](./configuration.md)。

遇到概念或边界问题时，再查 [核心术语](./concepts.md)。
